# Srinivas M — Professional Portfolio

Responsive personal portfolio built with HTML, CSS, and JavaScript.

## Included
- Professional portfolio homepage
- About, skills, projects, experience, education, certifications, and contact sections
- Resume and professional profile photo
- Direct GitHub links for project repositories
- Responsive navigation and scroll animations

## Project links
- Retail Intelligence System: https://github.com/srinivas556/retail-intelligence-system
- Attendance Management System: https://github.com/srinivas556/attendence-management-system
- Responsive Web Development: GitHub profile link is provided until the exact repository is selected.

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Upload all files to the portfolio repository and enable GitHub Pages from:
Settings → Pages → Deploy from branch → main → /(root)
